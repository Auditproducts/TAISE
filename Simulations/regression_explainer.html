Chapter One

What is Regression?

Regression is a statistical method that lets us understand how one variable changes in relation to another. If you can observe two things happening together, regression helps you figure out the rule connecting them — and use that rule to predict the future.

ŷ = β₀ + β₁x + ε ŷ = predicted output  ·  β₀ = intercept  ·  β₁ = slope  ·  ε = error (noise)

The idea is simple: find the line (or curve) that best describes the relationship in your data. Once you have that line, plug in a new value of x and get a prediction for y.

Dependent Variable

The Output — y

The thing you're trying to predict or explain. Also called the response variable. Example: house price, exam score, sales revenue.

Independent Variable

The Input — x

The thing you use to make predictions. Also called a predictor or feature. Example: house size, study hours, ad spend.

The Line

Best Fit

The goal of regression is to find the line (or curve) that minimises the total error between predictions and actual values.

Real World Uses

Applications

Stock prices, medical dosages, climate modelling, credit scoring, sports analytics, economic forecasting.

The most common method — Ordinary Least Squares (OLS) — finds the line that minimises the sum of squared residuals (the vertical distances between each data point and the line). Head to Draw & Fit to see this live.

Chapter Three

Types of Regression

Linear regression is just the beginning. Different problems call for different regression techniques.

ŷ = β₀ + β₁xOne predictor → one outcome. The classic.

Simple Linear Regression models the relationship between a single independent variable and a dependent variable using a straight line. It's the foundation of all regression analysis.

Example: predicting a student's exam score from hours studied.

ŷ = β₀ + β₁x₁ + β₂x₂ + … + βₙxₙMany predictors → one outcome. More realistic.

Multiple Linear Regression uses two or more predictor variables. This lets us model complex real-world situations where multiple factors influence an outcome.

Example: predicting house price from size, location, number of rooms, and age.

Visualising Multiple Regression

Beyond 2D

With two predictors, the "line" becomes a plane in 3D space. With more predictors, it's a hyperplane — impossible to visualise but mathematically well-defined.

ŷ = β₀ + β₁x + β₂x² + β₃x³…Curves, not just lines. For non-linear relationships.

Polynomial Regression fits a curved line by adding higher powers of x. It's still a linear model (linear in the coefficients) but can model non-linear patterns.

Example: modelling the trajectory of a thrown ball, or the growth rate of a population.

P(y=1) = 1 / (1 + e-(β₀+β₁x))Predicts probabilities. Output is always between 0 and 1.

Logistic Regression is used when the output is a category (yes/no, spam/not spam). It models the probability of a class using an S-shaped (sigmoid) curve.

Example: predicting if an email is spam, or if a patient has a disease.

Loss = Σ(y - ŷ)² + λΣβ²Adds a penalty to prevent overfitting. λ controls the strength.

Ridge Regression (L2) and Lasso (L1) add a penalty term to the loss function to shrink large coefficients. This prevents overfitting and handles multicollinearity.

Lasso can reduce some coefficients to exactly zero — effectively performing feature selection.

Ridge (L2)

Shrinks all coefficients

Good when all features contribute a little. Coefficients approach zero but never reach it.

Lasso (L1)

Sets some to zero

Good for sparse models. Automatically selects the most important features.

Chapter Four

Measuring the Fit

How do we know if our regression model is any good? These metrics help us evaluate its performance.

Goodness of Fit

R² — Coefficient of Determination

Tells you what proportion of variance in y is explained by x. R² = 1 is perfect; R² = 0 means the model explains nothing. R² = 0.85 means 85% of variation is captured.

Error Magnitude

RMSE — Root Mean Square Error

The average distance between predictions and actual values, in the same units as y. Lower is better. Sensitive to outliers.

Robust Error

MAE — Mean Absolute Error

Average absolute difference between predictions and actual values. More robust to outliers than RMSE.

Model Complexity

Adjusted R²

Like R² but penalises adding unnecessary predictors. Use this when comparing models with different numbers of features.

Chapter Five

Key Assumptions

Linear regression only works well when certain conditions are met. Violating these leads to biased or unreliable estimates.

Assumption 1

Linearity

The relationship between x and y must be linear. Check with a scatter plot. If the pattern is curved, consider polynomial regression.

Assumption 2

Independence

Observations must be independent of each other. Time series data often violates this (autocorrelation). Check with the Durbin-Watson test.

Assumption 3

Homoscedasticity

The variance of residuals must be constant across all levels of x. If residuals fan out, this is violated (heteroscedasticity).

Assumption 4

Normal Residuals

Residuals should be approximately normally distributed. Check with a Q-Q plot or histogram of residuals.

Assumption 5 (Multiple)

No Multicollinearity

In multiple regression, predictors should not be highly correlated with each other. Check with VIF (Variance Inflation Factor).

Assumption 6

No Influential Outliers

Extreme outliers can heavily distort the regression line. Use Cook's Distance to identify high-influence points.
