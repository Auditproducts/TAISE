The math underneath every ML model

Four ideas — vector, matrix, dot product, and matrix × vector — explain almost everything a machine learning model does under the hood. Adjust the numbers below and watch what changes.

01

What is a vector?

An ordered list of numbers. Also an arrow — a length and a direction, starting at the origin.

A vector like v = (3, 2) is one point described by two numbers. In machine learning, a vector usually describes one thing: a customer, an image, a word — each one turned into a list of numbers so a model can do arithmetic on it.

What is a matrix?

A grid of numbers. One easy way to read it: each column is just a vector.

A matrix is a table of numbers arranged in rows and columns. You can think of a 2×2 matrix as two vectors side by side — column 1 in amber, column 2 in teal. Soon you'll see this matrix can also act as a machine that reshapes any vector you feed it.

Dot product

Multiply matching entries, add them up. A single number that measures how much two vectors point the same way.

v · w = v₁w₁ + v₂w₂. When two vectors point in a similar direction the dot product is large and positive; at a right angle it's zero; pointing opposite ways it's negative. This is the arithmetic behind measuring similarity — between two embeddings, two documents, two user preferences.

Matrix × vector

Feed a vector into a matrix, get a new vector out. This is a transformation — and it's the core computation inside a neural network.

Each output entry is a dot product of one matrix row with the input vector. The matrix can be applied on either side: Mv (matrix times a column vector) or vM (a row vector times a matrix) — same idea, numbers land differently. Toggle to compare.

05

Why machine learning cares

These four ideas aren't background math — they're literally what a model is doing at every step.

Data → vectors

An image, a sentence, a user profile — each gets turned into a vector of numbers (an embedding) before a model can touch it.

Weights → matrices

Every layer of a neural network stores what it has learned as a matrix of weights, W.

Similarity → dot product

Search, recommendations, and attention in transformers all boil down to a dot product between vectors.

A layer → matrix × vector

Passing data through a layer is exactly the matrix–vector product you just played with: y = Wx + b.

A batch → matrix × matrix

Process many data points at once by stacking their vectors into a matrix — one matrix multiplication handles the whole batch.

Training

"Learning" just means slowly adjusting the numbers inside those weight matrices so the outputs get more useful.
