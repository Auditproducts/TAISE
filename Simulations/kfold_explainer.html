What is K-Fold Cross Validation?
Your dataset is split into 5 equal chunks called folds. In each round, one fold is held out as the test set — the model is trained on the remaining 4 folds and tested on the one it has never seen. Click Next Round → to begin.

Final CV Accuracy —
Average of all 5 test scores. Every data point was tested exactly once, making this estimate far more reliable than a single train/test split.
Why it matters
No data point is wasted
Every sample gets to be in the test set exactly once. With a small dataset, this is far better than permanently setting aside 20% just for testing.
The problem it solves
Avoiding lucky splits
Testing once could give you a misleadingly high or low score depending on which samples ended up in the test set by chance. K-fold averages this out.
Choosing K
K = 5 or 10 is standard
Higher K = more training data per round, but slower. K=5 is a good default. K=n (Leave-One-Out CV) is the extreme case — each sample is its own test set.
Key formula
Train on k−1, test on 1
If K=5, each round trains on 4 folds (k−1) and tests on 1 fold. The test fold rotates each round until every fold has been the test set once.
