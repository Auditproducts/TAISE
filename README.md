# About TAISE

**TAISE** stands for **Trusted AI Safety Expert**.

The TAISE certificate is developed by the **Cloud Security Alliance (CSA)** in partnership with **Northeastern University**. It is designed to provide professionals with knowledge and practical understanding needed to support the **safe, secure, and responsible development and deployment of AI systems**.

The overall objective is to understand how AI systems can be designed, developed, deployed, governed, secured, monitored, and improved responsibly across their lifecycle.

---

# TAISE Exam — CSA

According to the current CSA information, the TAISE examination consists of:

| Exam Feature         | Details                             |
| -------------------- | ----------------------------------- |
| Certification        | Trusted AI Safety Expert (TAISE)    |
| Organization         | Cloud Security Alliance (CSA)       |
| Developed with       | Northeastern University             |
| Exam format          | Multiple-choice                     |
| Number of questions  | 60                                  |
| Questions per module | 6                                   |
| Time limit           | 120 minutes                         |
| Passing score        | 80%                                 |
| Exam attempts        | 2 attempts included with the bundle |
| Prerequisites        | No prerequisites                    |
| Exam delivery        | Online                              |
| Exam type            | Open-book and unproctored           |

CSA states that the two attempts included with the purchase are valid for two years.

### What does an 80% passing score mean?

The examination contains **60 questions** and requires an **80% score**.

That means a candidate needs approximately:

**48 correct answers out of 60**

to achieve an 80% score.

However, candidates should not prepare with the mindset of simply reaching the minimum passing score. A stronger preparation strategy is to aim for a comfortable margin above the passing threshold.

# TAISE Exam Structure

TAISE currently consists of **10 modules**, covering the major areas of trustworthy AI, safety, security, governance, and responsible AI adoption.

# The 10 Modules at a Glance

| #  | TAISE Module                                      |
| -- | ------------------------------------------------- |
| 1  | Introduction to AI                                |
| 2  | Generative AI Architecture and Design             |
| 3  | Generative AI Use Cases and Applications          |
| 4  | Ethics, Transparency, and Explainability in AI    |
| 5  | AI Model Lifecycle and Threat Taxonomy            |
| 6  | Model Governance, Risk Management, and Compliance |
| 7  | Introduction to AI Security and Safety            |
| 8  | Cloud and AI Security                             |
| 9  | Data Security and Privacy AI Systems              |
| 10 | Continuous Learning and Adaption                  |

The module structure above follows the current CSA TAISE curriculum information.
